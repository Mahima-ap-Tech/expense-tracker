# 💰 SpendWise – Personal Expense Tracker

## 📌 Project Description

SpendWise is a personal expense tracking web application developed using **Python and Streamlit**. It helps users manage daily expenses, set budgets, organize spending into categories, and monitor their financial activities through an interactive dashboard.

The application provides a simple and user-friendly interface to make expense management easier and more organized.

## 🛠️ Technologies Used

### 🐍 Python
- Used as the core programming language.
- Handles application logic and expense calculations.
- Manages user interactions and application functionality.

### 🎈 Streamlit
- A Python framework used to build interactive web applications.
- Creates the user interface, navigation, input fields, and dashboard.
- Helps develop web applications without requiring HTML, CSS, or JavaScript.

### 🐼 Pandas
- A Python library used for data manipulation and analysis.
- Organizes expense records using DataFrames.
- Helps calculate total expenses and analyze spending patterns.

## 🎯 Project Objective

The main objective of SpendWise is to develop a simple and interactive financial management application that helps users:

- 💸 Track daily expenses.
- 🎯 Set and manage budgets.
- 📂 Categorize expenses.
- 📊 Monitor total spending.
- 📅 Track expenses by date.
- 📈 Understand spending patterns.
- 💡 Improve personal financial management.

## 🎈 Streamlit Concepts Used

| Concept | Description |
|---|---|
| `st.title()` | Displays the main heading. |
| `st.write()` | Displays text and information. |
| `st.text_input()` | Accepts text input from users. |
| `st.number_input()` | Accepts numerical values. |
| `st.date_input()` | Allows users to select dates. |
| `st.button()` | Creates interactive buttons. |
| `st.selectbox()` | Allows users to select options. |
| `st.session_state` | Maintains data across app reruns. |
| `st.sidebar` | Creates sidebar navigation. |
| `st.columns()` | Organizes content into columns. |
| `st.markdown()` | Displays formatted content and custom styling. |
| `st.set_page_config()` | Configures the application page. |

## 🐼 Pandas Concepts Used

| Concept | Description |
|---|---|
| `pd.DataFrame()` | Creates a tabular structure for expense data. |
| DataFrame | Organizes expense records into rows and columns. |
| Column Selection | Accesses specific expense information. |
| `sum()` | Calculates total expenses. |
| Filtering | Retrieves expenses based on specific conditions. |
| `groupby()` | Groups expenses by category. |
| `sort_values()` | Sorts expense records. |

## 🚀 How to Run the Project


```bash

```

```bash

```

